# Изменения

## 1.2.0

- Диаграммы сохраняют позиции и скрытые классы, ручные маршруты, фильтры, тему,
  масштаб и центр видимой области в настройках проекта. Состояние восстанавливается при повторном
  построении диаграммы после перезапуска IDE.

## 1.1.0

- Стрелки выбирают сторону подключения по положению классов и обходят другие карточки.
- Маршрут пересчитывается при перемещении любого класса, включая карточки-препятствия.
- Перетаскивание линии создаёт ручную точку; двойной щелчок добавляет новую точку изгиба.
- Можно перемещать точки маршрута и крепления стрелки к границе исходного или целевого класса.
- Delete удаляет выбранную точку, R сбрасывает выбранную стрелку, "Автострелки" сбрасывает все маршруты.
- При перетаскивании с Shift карточка притягивается к краям и центрам других карточек.
- Фильтры и обновление неизменившихся связей сохраняют ручное расположение и маршруты.
- SVG и PNG используют текущие маршруты; управляющие маркеры в экспорт не попадают.
- Исправлен экспорт подписи прямой стрелки из двух точек.
- Добавлены проверки маршрутов, мыши и экспорта, а также GitHub Actions для ядра без установленной IDE.

## 1.0.0

- Построение UML по Java-классам, файлам и папкам через Java PSI.
- Поля, методы, наследование, реализация интерфейсов, ассоциации и зависимости.
- Автоматическая раскладка, перемещение карточек, масштаб, поиск и переход к исходнику.
- Светлая и тёмная темы; экспорт SVG, PNG и PlantUML.

Версия 1.0.0 сохранена в локальных ZIP-архивах. Эта запись не означает, что для неё уже создан Git-тег или GitHub Release.
