# Class Diagrams for OpenIDE 1.2.0

Диаграмма сохраняет расположение классов и ручные маршруты стрелок между запусками OpenIDE.

## Что изменилось

- Сохраняются позиции и скрытые классы, точки и места крепления стрелок, фильтры, тема, масштаб и центр видимой области.
- После перезапуска IDE выберите те же файлы или папки и снова постройте диаграмму. Состояние восстановится из локальных настроек проекта `.idea/workspace.xml`.
- Если класс или связь удалены, их настройки пропускаются. Новые классы размещаются рядом с сохранёнными карточками.
- Кнопка "Раскладка" сбрасывает ручное расположение, скрытые классы и маршруты.

## Установка

1. Скачайте `class-diagrams-1.2.0.zip` из Assets.
2. В OpenIDE откройте Settings, затем Plugins. Нажмите шестерёнку и выберите Install Plugin from Disk...
3. Выберите ZIP без распаковки. Перезапустите IDE, если потребуется.

Версия 1.2.0 обновляет установленную 1.1.0. Проверено с OpenIDE 2026.2.3 на Windows.

## Ограничения

- Поддерживается Java.
- Если выбранные файлы или папки переименованы либо перемещены, прежняя диаграмма не находится по новому пути.
- Состояние хранится в локальном `workspace.xml` проекта и не переносится через репозиторий.

Архив `*-sources.zip` содержит исходники; в `SHA256SUMS-1.2.0.txt` записаны контрольные суммы.
