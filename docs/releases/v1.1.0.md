# Class Diagrams for OpenIDE 1.1.0

Стрелки автоматически обходят классы и перестраиваются при их перемещении. Маршрут можно менять мышью.

## Управление стрелками

- **Потянуть линию / двойной щелчок** — добавить точку изгиба.
- **Потянуть квадрат** — изменить маршрут.
- **Потянуть круг** — изменить крепление к классу.
- **Delete** — удалить выбранную точку.
- **R** — сбросить выбранную стрелку.
- **«Автострелки»** — сбросить все стрелки, сохранив позиции классов.

Ручные маршруты сохраняются при переключении фильтров, обновлении неизменившихся связей и экспорте в SVG/PNG.

## Установка

1. Скачайте **class-diagrams-1.1.0.zip** из **Assets**.
2. В OpenIDE: **Settings → Plugins → ⚙ → Install Plugin from Disk…**
3. Выберите ZIP **без распаковки**. Перезапустите IDE, если потребуется.

Версия 1.0.0 обновится автоматически.

**Проверено:** OpenIDE 2026.2.3, Windows.

## Важно

- Поддерживается **Java**.
- Правка стрелок не меняет код.
- Позиции и маршруты не сохраняются после перезапуска IDE.
- **Оранжевая стрелка** — маршрут заблокирован. Раздвиньте классы, переместите точку или нажмите **R**.

**Другие файлы:** `*-sources.zip` — исходники; `SHA256SUMS-1.1.0.txt` — контрольные суммы.
