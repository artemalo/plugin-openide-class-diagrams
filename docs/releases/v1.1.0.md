# Class Diagrams for OpenIDE 1.1.0

Стрелки автоматически обходят классы и перестраиваются при их перемещении. Маршрут можно менять мышью.

## Управление стрелками

- Потяните линию или дважды щёлкните по ней, чтобы добавить точку изгиба.
- Потяните квадратный маркер, чтобы изменить маршрут.
- Потяните круглый маркер, чтобы изменить место крепления стрелки к классу.
- Delete удаляет выбранную точку.
- R сбрасывает маршрут выбранной стрелки.
- "Автострелки" сбрасывает маршруты всех стрелок, сохраняя позиции классов.

Ручные маршруты сохраняются при переключении фильтров, обновлении неизменившихся связей и экспорте в SVG/PNG.
При перетаскивании класса с Shift его края и центр притягиваются к краям и центрам других карточек.

## Установка

1. Скачайте `class-diagrams-1.1.0.zip` из Assets.
2. В OpenIDE откройте Settings, затем Plugins. Нажмите шестерёнку и выберите Install Plugin from Disk...
3. Выберите ZIP без распаковки. Перезапустите IDE, если потребуется.

Версия 1.0.0 обновится автоматически.

Проверено с OpenIDE 2026.2.3 на Windows.

## Ограничения

- Поддерживается Java.
- Правка стрелок не меняет код.
- Позиции и маршруты не сохраняются после перезапуска IDE.
- Оранжевая стрелка означает, что маршрут заблокирован. Раздвиньте классы, переместите точку или нажмите R.

Архив `*-sources.zip` содержит исходники; в `SHA256SUMS-1.1.0.txt` записаны контрольные суммы.
