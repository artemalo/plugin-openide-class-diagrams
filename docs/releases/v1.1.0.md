# Class Diagrams for OpenIDE 1.1.0

Стрелки теперь автоматически подстраиваются под расположение классов: выбирают
подходящие стороны карточек и прокладывают прямоугольный маршрут в обход других классов.
Маршрут можно поправить вручную прямо на диаграмме.

## Новое

- Перетащите линию, чтобы создать точку изгиба; двойной щелчок добавляет ещё одну.
- Перетаскивайте квадратные точки маршрута и круглые точки крепления к классам.
- Delete удаляет выбранную точку, R возвращает выбранную стрелку в автоматический режим.
- Кнопка «Автострелки» сбрасывает маршруты всех стрелок, сохраняя позиции классов.
- Ручные точки сохраняются при переключении фильтров и обновлении неизменившихся связей.
- SVG и PNG сохраняют ручной маршрут.

## Установка и обновление

Скачайте **class-diagrams-1.1.0.zip** из Assets. В OpenIDE откройте
**Settings → Plugins → ⚙ → Install Plugin from Disk…**, выберите ZIP целиком
и перезапустите IDE, если потребуется. Распаковывать ZIP не нужно.
Пакет использует тот же ID плагина и обновляет версию 1.0.0 в установленном профиле.

Проверенная среда: **OpenIDE 2026.2.3 / build 262.10968.63.1, Windows**.
Диапазон совместимости в описании плагина: **262.***. Другие сборки этого диапазона отдельно не проверялись.

## Ограничения

Анализируется Java. Редактирование стрелки меняет её внешний маршрут, а не исходный код
и не тип связи UML. Расположение и ручные точки пока не сохраняются между сеансами IDE.
Если карточки перекрываются либо ручная точка оказалась внутри карточки, маршрут
подсвечивается оранжевым: раздвиньте классы, переместите точку или сбросьте стрелку.

`class-diagrams-1.1.0-sources.zip` содержит исходники. `SHA256SUMS-1.1.0.txt`
содержит контрольные суммы обоих архивов.
